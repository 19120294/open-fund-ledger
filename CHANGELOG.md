# Changelog

All notable changes to Open Fund Ledger are documented here.

The project uses semantic versioning for public releases.

## 0.1.0 - 2026-08-20

### Added

- Privacy-first, browser-only community fund dashboard.
- Synthetic demo ledger and downloadable CSV template.
- Local CSV parsing with aggregated validation feedback.
- Income, expense, balance, and transaction summaries.
- Search, type, and category filters.
- Expense category breakdown and filtered CSV export.
- Responsive, keyboard-friendly, screen-reader-conscious interface.
- Unit tests, strict TypeScript checks, continuous integration, and Pages deployment.
- Contributor, security, roadmap, and community launch documentation.

### Security and privacy

- No backend, user account, analytics, cookie, or third-party runtime script.
- Imported data remains in browser memory and is never uploaded.
- User-provided values are rendered as text rather than HTML.
- CSV imports are limited to 2 MB.
