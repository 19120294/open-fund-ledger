# Roadmap

Open Fund Ledger follows a small, evidence-led roadmap. New features should
preserve local-only processing, accessible output, portable CSV data, and a
static deployment.

## Now

The first public release provides:

- local CSV import and validation;
- income, expense, balance, and transaction summaries;
- search, type, and category filters;
- expense category breakdown;
- filtered CSV export;
- responsive and accessible presentation;
- automated tests, CI, and GitHub Pages deployment.

## How priorities change

Issues move forward when they solve a demonstrated community need, have a
privacy-safe design, and can be maintained by a small volunteer team. Comments
describing a real use case are more useful than feature votes without context.

To propose work, open an issue describing the users, the transparency problem,
the expected outcome, and any privacy or accessibility risks.
