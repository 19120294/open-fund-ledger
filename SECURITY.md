# Security and privacy policy

## Supported version

The latest commit on `main` is supported.

## Reporting a concern

Please do not publish sensitive data or an exploitable privacy issue in a public
issue. Contact the maintainer through the GitHub profile at
https://github.com/19120294 and include:

- the affected feature,
- steps to reproduce,
- the potential privacy or security impact,
- a suggested mitigation, if available.

## Data handling

Open Fund Ledger has no backend. CSV files are parsed in the browser and are
not intentionally transmitted or persisted. A deployment owner is responsible
for reviewing any ledger they publish and removing personal or sensitive data.
