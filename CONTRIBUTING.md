# Contributing

Thank you for helping make community finances easier to understand.

## Before opening a change

- Open an issue for large features or changes to the CSV schema.
- Keep the application static and privacy-first.
- Do not add analytics, remote storage, or third-party scripts without prior
  discussion.
- Never commit real donor identities or sensitive financial information.

## Development

```bash
npm install
npm run typecheck
npm test
npm run build
```

## Pull requests

1. Create a focused branch.
2. Add or update tests for behavior changes.
3. Update the README when public behavior or the CSV schema changes.
4. Explain the user problem, solution, accessibility impact, and privacy impact.
5. Keep commits focused and use clear messages.
